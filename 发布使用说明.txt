蜜蜂关键点标注器 v1.7.4
========================

一、运行方法

1. 支持 Windows 10/11 64 位。
2. 请完整复制整个软件文件夹后再运行，不要单独复制 EXE。
3. 双击“蜜蜂关键点标注器.exe”。
4. 本软件不需要安装 Python。
5. 必须保留“_internal”文件夹，不能只复制 EXE。

二、打开标注任务

1. 点击“打开文件夹”。
2. 选择分配给自己的“区段_xx”文件夹。
3. 文件夹中需要同时保留 JPG 图片和同名 JSON 标注文件。
4. 软件会读取 JSON 中已有的 bee 检测框。

界面分区：

- 顶部“文件与图片”：打开任务、保存和切换图片。
- 顶部“关键点标签”：选择 head/tail 或管理自定义标签。
- 顶部“中心对称辅助”：控制自动补点和对称比例。
- 左侧“当前检测框”：放大后精确点击关键点。
- 右侧“整图鸟瞰”：查看全部框并点击选择目标。
- 底部黄色“TRACK ID 复审”：传播、确认、交换头尾和检查异常。
- 最底部状态栏：显示当前图片、检测框、确认进度与 Track ID。

三、关键点标注

左键：标注当前标签；开启中心对称时，可自动补充对应点。
右键：开启中心对称时手动标注 tail。
中键：删除鼠标附近的关键点。
滚轮：切换上一个或下一个检测框。

调整检测框：
- 普通左键短按仍然标注关键点。
- 在框内长按鼠标左键后拖动：移动整个检测框。
- 在八个白色控制点上长按后拖动：按对应方向调整框的大小。
- 在“快捷键”设置窗口可以把长按延时调整为 100～1000ms，默认 250ms。
- Ctrl+左键拖动保留为无需等待的快速调框方式。
- 左侧放大视图和右侧鸟瞰图都可以操作。
- 松开鼠标后自动保存；移动框时关键点同步平移，缩放框时关键点保持原图绝对位置不变。
- 调整错误时按 Ctrl+Z 撤销。

默认快捷键：

Z / C：普通上一张、下一张图片
A / D：同一 Track ID 的上一帧、下一帧
R：将当前整帧所有框的关键点按 Track ID 复制到下一张，并自动切换过去
Q / E：上一个、下一个检测框
G：打开本帧检测框清单；默认只显示未完成框，单击序号直接进入
鼠标侧键 1 / 2：上一个、下一个检测框
1 / 2：切换第 1、第 2 个关键点标签
Ctrl+M：开启或关闭中心对称
Ctrl+Z：撤销
Delete：删除当前标签点
Shift+Delete：删除当前框全部关键点
Ctrl+K：设置快捷键
F1：打开完整帮助

字母快捷键按物理按键识别，不受中文/英文输入法、Caps Lock 或大小写影响；输入框获得焦点时快捷键会自动暂停。

按 Track ID 标注模式：

1. 点击底部“进入按 ID 标注模式”。
2. A / D：只浏览当前 ID 的上一帧、下一帧，不确认黄色点。
3. E：明确确认当前图片中该 ID 的 head/tail 正确，清除黄色待确认状态，复制到当前 ID 的下一张并自动前进。
4. Q：返回上一个 Track ID，并从它的第一帧开始。
5. W：进入下一个 Track ID，优先跳到该 ID 的第一处未完成位置。
6. G：打开 Track ID 清单，查看每个 ID 的总帧数、已完成帧和剩余帧；单击 ID 直接进入。
7. 一个 ID 全部完成后，弹窗中按 E 进入下一个未完成 ID，按 Q 返回上一个 ID。
8. 完成标准：每次出现都恰好有一个人工确认的 head 和 tail，不能残留黄色待确认点。

按 ID 模式下，Q/E/G 会自动切换为对应的 ID 操作；退出该模式后恢复原始逐帧功能。
右侧鸟瞰图顶部会显示“当前 Track ID、轨迹第几张/共几张、已确认/剩余”；旧版本中已人工标好但残留的待确认状态会在打开任务时自动修复。

四、Track ID 传播与复审

相邻帧整帧复制：

1. 在当前图片完成需要的 head/tail 标注。
2. 按 R，软件会遍历下一张图片中的所有检测框。
3. 相同 Track ID 的关键点会按框内相对位置复制，并显示为黄色待确认点。
4. 软件自动保存并切换到下一张图片；已有人工确认点不会被覆盖。
5. 没有相同 Track ID 或源框没有关键点的目标框会自动跳过。

自动复审：

- 黄色框被选中查看后，切换到其他框或其他图片时会自动确认并变成绿色。
- 只有正好包含一个 head 和一个 tail 的框才会自动确认；缺点或重复点会继续保持待处理状态。
- 右侧鸟瞰图顶部显示本帧“已检查 / 总数 / 剩余”框数，以及检测框总数和已标关键点框数。
- 复审进度保存在 JSON 中，重新打开软件不会丢失。
- 自动确认错误时按 Ctrl+Z，软件会撤销并返回对应图片和检测框。
- 当每个框都恰好有一个已确认的 head 和 tail 时，会弹出一次“本页标注完成”提示。
- 按 G 可查看序号、Track ID、标注状态和缺少内容，并直接跳到未完成框。

整条轨迹传播：

1. 先在一帧中人工标好同一蜜蜂的 head 和 tail。
2. 选中该框，按 Ctrl+P 或点击“ID传播”。
3. 软件会把关键点传播到同 Track ID 的其他帧。
4. 黄色点表示自动建议，必须人工检查；按 A/D 沿同一 ID 前后切换。
5. 当前框正确时按空格确认，框会变成绿色。
6. head/tail 反了时按 X 交换；按 N 跳到下一处待确认或异常。

传播不会覆盖人工确认点，只会补充缺失点或更新旧的黄色建议点。已有 Track ID 时优先使用 ID 传播，IoU 传播仅作为旧数据的备用方法。

五、保存与提交

1. 新增、修改或删除关键点，以及调整检测框后会自动保存；连续操作会合并写盘，切换图片或关闭软件时会强制保存。
2. 软件第一次修改 JSON 时会生成“.json.bak”备份。
3. 完成后退出软件，将整个任务文件夹交回负责人。
4. 不要重命名、移动或删除任务中的 JPG 和 JSON 文件。

六、常见问题

1. 软件打不开：确认压缩包已经完整解压，并且“_internal”文件夹与 EXE 在同一目录。
2. 侧键无法识别：在鼠标驱动中将侧键设置为“前进/后退（XButton1/XButton2）”，不要设置成键盘宏。
3. 安全软件出现提示：先把提示截图发给负责人确认，不要盲目放行。
4. 中文输入法开启时无需切换英文，Q/E/A/D/R/G 等字母快捷键仍可直接使用。
